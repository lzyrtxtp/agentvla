THE IDEA

Overview

Multi-stage manipulation requires more than generating the next action. A robot must interpret task rules, remember prior interactions, and decide when a step has actually finished.

AgentVLA assigns these responsibilities to three specialized roles. A planner dispatches grounded instructions, a VLA executor generates continuous actions, and a progress monitor records observed outcomes to inform what happens next.

The same trained planner and monitor can be reused with both π0.5 and X-VLA, without retraining either high-level module.

METHOD

Method Overview

A shared step description links the executor’s
current goal to the monitor’s completion check.

01 / PLAN

High-Level Task Planner

Combines task rules, the current scene, and recorded progress to maintain the remaining ordered plan and dispatch the active step.

02 / ACT

VLA Executor

Generates continuous actions toward the active goal from live visual and proprioceptive observations. The instruction stays fixed within each attempt.

03 / ASSESS

Task Progress Monitor

Assesses interaction outcomes and updates the progress record, returning feedback to the planner for step advancement or plan revision.

WHY PROGRESS MATTERS

Similar scenes can have different interaction histories.

Before and after a button press, the scene can look nearly identical. A progress record retains the observed press so the planner can select the next target in the required order.

INTERACTION-ALIGNED SUPERVISION

ECIA & AgentVLA-Interact

Evidence-Constrained Interaction Alignment (ECIA)
connects task semantics, actions, and outcomes.

ECIA converts unsegmented robot demonstrations into shared interaction records. These records provide aligned supervision for the remaining plan, demonstration action chunks, and execution outcomes with updated progress.
